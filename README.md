# Undertaker7 · GitHub Pages 作品集

这是可直接发布的纯静态版本，不需要 Node.js、数据库或服务器。

## 发布方法

1. 将本文件夹中的所有文件和文件夹上传到 GitHub 仓库根目录。
2. 打开仓库 Settings → Pages。
3. 在 Build and deployment 中选择 Deploy from a branch。
4. Branch 选择 main，目录选择 /(root)，然后保存。
5. 等待 GitHub Pages 完成部署。

如果仓库名不是 用户名.github.io，网站地址通常是 https://用户名.github.io/仓库名/。
