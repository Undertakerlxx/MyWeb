FLOW FIELD / CORE PIPELINE

流场寻路基础

INTEGRATION · DIRECTION · STEERING

流场并不为每个单位生成一条独立路径，而是为整张地图预先计算“朝哪里走”。所有单位读取自己所在格子的方向，持续顺着同一份场移动。

THREE CORE STEPS

从目标反推整张地图的移动方向

01 / INTEGRATION遍历地图网格，计算每个格子到目标格的累计代价，得到积分场。
02 / DIRECTION检查周围八格，指向累计代价最小的合法邻居，得到方向场。
03 / STEERING每个角色读取当前单格的方向，持续沿向量场移动。
04 / SHARED READ同一目标下的所有单位复用同一份积分值和方向，不重复寻路。
目标或目标区域→积分场
累计代价→方向场
最小代价邻居→单位持续顺流移动
BUILD PHASES

流场构建的四个核心阶段

01 / SAFE MAP先构建安全地图，确认哪些格子可供当前尺寸的单位通过。
02 / TARGET SET在每个安全连通区域中寻找驻留环种子，作为目标集合。
03 / BFS从所有种子同时 BFS，填充 Distance = 0、1、2……的积分场。
04 / FLOW让每个格子指向积分值更小的合法邻居，生成方向场并开始寻路。
02

RUNTIME / DESIGN DETAILS

关键实现设计

STAY · CLEARANCE · SMOOTH · SWEEP

共享方向解决“往哪里走”，但实际游戏中的停驻距离、角色尺寸、移动平滑和碰撞安全，需要在流场读取之后继续处理。

驻留环种子格

弹幕游戏中的远程敌人不会移动到主角脸上才射击，而要保持一段射击距离。因此将类圆环上的格子作为目标种子。若驻留环已被占满，则回退到更外侧、距驻留环最近的可用网格作为目标。

Clearance 构建

障碍占据的格子不可通行，但 3D 单位还具有半径和高度。即使中心点可通过，胶囊体也可能擦墙、卡角或生成后嵌入碰撞体。比如宽度 0.8m 的窄缝无法容纳直径 1.0m 的单位，应标记为不可通行。

双线性插值

单位通常不会精确踩在格子中心。根据附近四个格子的方向和单位到它们中心的距离计算权重，得到更合理的方向向量，减少格子边界的方向突变，让轨迹和朝向更圆滑。

胶囊体扫掠与滑墙

通过 CastCollider 将单位的实际碰撞形状沿移动向量连续扫过整段路径，寻找首次接触点。它处理贴墙穿模、高速位移隧穿和斜角穿障；碰墙后移除指向墙内的分量，保留沿墙分量，实现滑墙移动。
