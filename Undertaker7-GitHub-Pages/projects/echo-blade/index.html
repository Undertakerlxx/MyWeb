ACTION GAME · 2026

EchoBlade

第三人称动作战斗 Demo

C++Unreal EngineGAS

PROJECT INTRO

项目介绍

一个以精准格挡和连招派生为核心的第三人称动作 Demo，重点验证战斗手感、状态组织与动画驱动的客户端架构。

CHALLENGE

攻击、位移、受击与动画事件相互交织，既要保证输入响应足够快，也要避免状态切换失控和逻辑散落在动画蓝图中。

OUTCOME

以 Gameplay Ability 和分层状态机重构战斗链路，形成可配置的招式数据；在 60fps 下将输入到动作反馈稳定在 50ms 内。

<50ms输入反馈延迟
60fps目标战斗帧率
18可配置招式

SYSTEM MAP

项目结构

从核心体验出发，把产品拆成边界清楚、能独立演进的四个部分。

01

角色控制

处理移动、镜头、锁定与输入缓冲，将玩家意图转为可被战斗系统消费的命令。

02

战斗能力

使用 GAS 组织攻击、闪避、格挡与受击，统一冷却、消耗、标签和效果结算。

03

动画桥接

Montage 与 Notify 只负责时间窗口和表现事件，战斗规则仍由 C++ 状态管理。

04

数据配置

招式段、派生条件、伤害与镜头反馈全部数据化，方便策划快速调整手感。

BEHIND THE PIXELS

细节设计思路

真正影响体验的，往往是那些看起来很小的决定。

A

输入缓冲服务于意图，而不是放宽一切

只在动作后摇的可取消窗口缓存一条有效输入，并根据动作优先级消费，避免连续按键带来失控的自动连招。

↳ 120ms 动态缓冲窗口
B

命中停顿不暂停整个世界

通过攻击者与受击者的局部时间缩放制造重量感，同时保持特效、镜头和 UI 正常更新。

↳ 手感与信息反馈同时保留
C

状态标签成为系统之间的共同语言

动画、移动、技能与 UI 不直接相互引用，而是围绕可查询的 Gameplay Tags 协作，降低模块耦合。

↳ 规则集中，表现解耦
