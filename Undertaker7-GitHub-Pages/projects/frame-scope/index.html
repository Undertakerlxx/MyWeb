FrameScope

客户端性能与资源巡检工具

Unity EditorC#Addressables

PROJECT INTRO

项目介绍

面向中小型 Unity 项目的编辑器巡检工具，一键定位重复资源、异常贴图、加载峰值和场景中的高开销对象。

CHALLENGE

性能问题往往散落在资源、脚本和场景配置中；Profiler 能看到结果，却很难把问题直接交回到对应的资产和负责人。

OUTCOME

建立可扩展的规则扫描与报告系统，将一次版本巡检从约 2 小时缩短到 6 分钟，并接入打包前检查。

6min完整项目巡检
27内置检查规则
41%峰值内存降低

SYSTEM MAP

项目结构

从核心体验出发，把产品拆成边界清楚、能独立演进的四个部分。

01

规则引擎

每条检查规则独立声明适用资源、严重级别与修复建议，可按项目需要自由组合。

02

资源索引

缓存 GUID、依赖关系和导入配置，避免每次巡检都完整遍历 AssetDatabase。

03

运行采样

在目标场景自动采集帧时间、GC、DrawCall 与加载事件，并关联到具体对象。

04

报告出口

编辑器内可一键定位资源，同时输出 JSON 和 HTML 报告供 CI 与团队评审使用。

BEHIND THE PIXELS

细节设计思路

真正影响体验的，往往是那些看起来很小的决定。

A

报告必须能直接抵达问题现场

每条结果都带资源路径、对象层级和快捷修复入口；开发者不需要在庞大的项目目录里再次搜索。

↳ 从发现到定位只需一次点击
B

先给证据，再给建议

规则展示命中的数据、阈值和影响范围，修复建议保持可选，避免工具在不同项目标准下做武断修改。

↳ 自动检测，人工决策
C

缓存也要可验证地失效

资源变更后按 GUID 增量更新索引，并提供缓存版本与完整重建入口，兼顾扫描速度和结果可信度。

↳ 增量巡检保持在分钟级
